# Scenario Guide（五场景骨架）

> 全场景骨架均建，eval 深度只保谈薪双场景。每场景给：时机 / 卡组结构 / top 压力招（mock 默认弹药）/ 场景禁忌。通用禁忌与 HR 应对见 cn-workplace-notes.md。

## 1. Offer 谈薪（默认场景）

- **时机**：口头 offer 意向明确之后、正式 offer 文件发出之前——这是全流程杠杆最高的窗口（对方已投入筛选成本，替换你要重走流程）。正式 offer 已发再谈，难度上一档但仍可谈（回复窗口内）。
- **卡组**：全套四型。锚定卡是核心；异议应对至少覆盖：压价、区间取底、画饼、反问底牌（当前薪资 / 竞争 offer）。
- **top 压力招**（mock 默认）：反问底牌 → 压价 → 画饼。
- **禁忌**：意向没确认就开谈数字（顺序反了会掉出候选池）；用〔待核〕数字当锚；虚报当前薪资（背调即翻车，等同虚构筹码 fatal）。
- **加分动作**：谈 package 不只谈 base（HR 的签字费权限往往比 base 弹性大）；到岗时间是你手里被低估的议题。

## 2. 在职提加薪

- **时机**：绩效周期节点前 4-6 周（预算未锁）、大项目交付后、接手显著扩大的职责时。**错时机**：公司裁员冻编期、老板刚被上面骂完、你刚犯错的当口。
- **卡组**：全套四型 + 前置一步——本场景的锚定卡依据不是市场数据而是**成果证据链**。证据链的书面梳理不归本件（→ loop-report-writer 的账本与述职材料）；本件只取其结论进 Brief（「过去一年职责从 X 扩到 Y，关键成果 A/B/C」）。
- **top 压力招**：拖延（「等年底统一调」）→ 权限甩锅（「名额不在我」）→ 画饼。
- **禁忌**：拿同事薪资对比当论据（在多数中国公司薪酬保密是纪律，此举直接引爆关系）；用离职威胁开场（那是最后一张台阶，且需要真 BATNA）；把家庭开销当理由（加薪的依据是价值不是需要）。
- **薪资倒挂**（新人高于老人）本身是站得住的加薪论据，但信息来路必须干净：走 HR 正式渠道申请薪酬复核 / 引用公开招聘 JD 的报价区间，**不引用私下打听的同事实数**（否则就踩了上一条禁忌）。
- **弱 BATNA 常态**：本场景多数用户 BATNA 弱（没在看机会）——按 batna-gate-guide.md 弱 BATNA 校准降档，核心工具是**调薪机制**（把「现在加」转化为「什么条件下、什么时点加、谁说了算」的书面约定）。

## 3. 拒绝与婉拒（拒绝不合理安排 / 婉拒 offer）

- **结构**：缓冲 → 理由 → 替代（三段缺一不可）。拒绝的坚定在决定本身，温度在表达方式。
- **卡组**：去锚定卡；开场卡与缓冲合并；异议应对覆盖「再考虑一下」「就这一次」类软磨；收尾卡改为关系维护句（婉拒 offer 时尤其重要——这家公司三年后可能还会遇到）。
- **拒绝不合理安排**（加班 / 越界任务）：理由用客观约束（在做的优先级、时间容量）而非价值判断（「这不该我做」）；替代给真实选项（「A 和 B 我只能保一个，你定优先级」把球还给分派人）。
- **top 压力招**：情绪施压（「大家都这样」）→ 软磨 → 上升引用（「这是上面的意思」）。
- **禁忌**：拒绝时道歉过载（三个「不好意思」= 立场自动软化）；婉拒 offer 时贬低对方公司（转发存活测试必挂）。

## 4. 提离职

- **法务红线（先于一切话术）**：书面辞职通知**送达即生效，通常不可单方撤回**（撤回须单位同意；具体以当地法规与公司实践为准）。所以：**绝不把递交书面辞职信当试探性筹码**——没拿到新 offer 签字件、没做好真走的准备，就不递书面件；口头意向沟通与书面通知是两个动作，顺序不能乱。涉及补偿金 / 仲裁 / 竞业的具体问题出本件边界 → 专业人士。
- **目标锚定**：本场景的目标是**干净体面地离开**，不是钓 counteroffer。想用离职换加薪的用户 → 引导回场景 2（那是加薪谈判，离职是它的最后台阶，顺序不能反）。
- **卡组**：开场卡（决定直陈，不留「挽留窗口」误读）+ 异议应对（挽留 / counteroffer / 情感牌 / 交接压力）+ 收尾卡（交接方案主动给出 = 体面的核心）。去锚定卡。
- **counteroffer 应对**：卡面预设立场——接受 counteroffer 常伴随信任受损、日后被优先替换的风险（从业者共识，非硬数据，程度取决于组织文化与老板风格）——这点如实告诉用户，决定权在用户；若用户倾向听 counteroffer，Brief 里先补「什么数字 / 条件会留下」的底线，否则那是场景 2 没谈完。
- **top 压力招**：情感牌（「团队正是用人的时候」）→ 交接绑架（「找到人再走」）→ 模糊挽留（「再给我们一次机会」无实质条件）。
- **禁忌**：离职理由攻击具体个人（转发必达本人）；在挽留压力下当场改口（任何改变决定的条件都要求书面）。
- **维权转出**：单位以扣离职证明 / 压工资要挟交接的，属维权场景而非谈判 → 走 SKILL.md rights-violation tripwire（劳动监察 / 12333 / 法律援助）。

## 5. 坏消息传达（项目延期 / 预算超支 / 负面结果上报）

- **结构**：直陈事实（第一句就是坏消息本身，不埋）→ 影响范围 → 已做处置 → 需要的决策。坏消息传达的缓冲不是拖延入题，而是**控制信息完整度**——一次说全，不挤牙膏。
- **卡组**：开场卡（直陈版）+ 异议应对（追责 / 「为什么现在才说」/ 连带质疑）+ 收尾卡（决策请求明确化）。
- **top 压力招**：追责（「谁的责任」）→ 时点质疑 → 扩大化（「还有什么瞒着」）。
- **禁忌**：坏消息分期披露（第二次补充 = 信任二次伤害，这也是「一次说全」的依据）；甩锅式归因开场（先处置后归因）；无处置方案裸报问题（把坏消息变成决策请求是本场景的核心转化）。
- **与场景 3 的边界**：拒绝是「我不做 X」，坏消息是「X 已经发生」——用户混着说时按后者走（先把事实盘清）。
