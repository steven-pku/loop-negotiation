# 中文职场谈薪实战注记

> **本文件整体为 practitioner consensus 层**（中文求职社区高热实战帖收敛 + 通行 HR 实务），非学术结论；具体公司制度差异大，**一切以用户实际情况为准**，卡面引用时按「常见做法」表述，不说「规定如此」。涉及劳动合同 / 竞业 / 仲裁的问题出本件边界 → 提示咨询专业人士。

## HR 常见动作与应对

| HR 动作 | 背后逻辑 | 应对 |
|---|---|---|
| 前置问「期望薪资」（简历表单 / 首轮电话） | 提前锁锚 + 筛预算 | 缓冲反问（见 brief-guide.md 分支表第三行）；表单必填时填窄区间且下限 ≥ 满意层 |
| 要求提供当前薪资流水 / 截图 | 以旧薪定新薪（压涨幅至常见 20-30% 内） | **分层应对**：① 先问用途与是否流程硬性要求 ② 非硬性 → 婉拒或延后（「我更希望按岗位本身的价值来谈」「等口头 offer 数字定下来，流水我马上补给你们」）③ 硬性流程节点（部分大厂/国企不提供即中止）→ 提示用户权衡后可选择性提供（作过往收入证明用，当场声明不接受它锁定新 offer 定价）④ 可脱敏非必要信息。**全程绝不虚报**——多数公司入职背调含薪资核验，虚报 = 撤 offer 甚至入职后解除的常见理由 |
| 报价时拆包装（「加上餐补房补其实有 X」） | 名义总包做大 | 收尾卡确认口径：base / 固定 / 浮动 / 福利分列，写进 offer 的才算 |
| 「我们薪资带宽就这样」 | 部分真（职级带宽真实存在）部分策略 | 转议题：带宽内顶格 + 签字费 + 定级复议（职级比当期 base 值钱） |
| 口头承诺（「以后有机会」「明年肯定调」） | 关单话术 | 一律要求落字（调薪 review 条款 / 邮件确认）；拒绝落字即按不存在计入决策。**软约束警示**：调薪 review 即便入 offer，可执行性仍软于 base/签字费（考核标准可主观化、执行人可更换）——它是弱筹码场景的止损工具，不是硬钱的等价物，勿拿确定的 base 让步换未评估的软承诺 |
| 「今天不定就给别人了」 | 制造紧迫 | 真伪判断：真候选竞争通常伴随流程加速的其他信号；标准应对「我需要 X 天走完手上的流程——能等我这几天，就是最大的诚意了」 |

## 场景通用禁忌（中文职场特有）

- **同事薪资对比当论据**：薪酬保密在多数公司是纪律红线，此论据一出，谈判主题瞬间从「你的价值」变成「你违规打听」。
- **越级谈薪**：跳过直属找隔级 / HR 直谈，在多数组织文化里对直属是关系核弹，收益极少覆盖成本。**例外**：直属授意、公司流程本就走 HRBP、直属存在利益冲突或长期不作为且已穷尽直接沟通——此时走正式机制（HRBP / 申诉通道）而非私下越级。
- **试用期内主动谈涨薪**：几乎无成功案例且标签负面；试用期能谈的是转正评估标准的明确化。**例外**：实际职责 / 地点 / 工作量与 offer 约定明显不符——那不是谈涨薪，是谈 offer 口径修正或转正 review 标准，可以正当提。
- **把 offer 当筹码到处晾**：拿 A 司 offer 压 B 司可以（真实筹码），但同时晾三家且被发现节奏拖延 → 三家同时降温。
- **情绪化「裸辞宣言」**：见 batna-gate-guide.md 幻想 BATNA 探底。

## Offer 细节确认清单（收尾卡 / 落字用）

- base 与发薪月数（12 / 13 / 14+ 薪，绩效月薪算法）
- 绩效奖金：目标值、保底与封顶、考核周期、入职首年折算方式
- 签字费：金额、发放时点、离职返还条款
- 期权 / RSU：数量、行权价、vesting 节奏、离职处理
- 职级定级 + 定级复议窗口
- 社保公积金缴纳基数（按全额还是按最低——五年维度差额巨大）
- 年假天数与生效时点；远程 / 弹性安排是否入文
- 调薪机制：普调周期 + 个案 review 约定（如有谈定，必须入 offer 或邮件）
- 竞业限制条款范围与补偿标准（有疑义 → 专业人士，本件不做法律判断）
- 到岗时间与前置条件（背调 / 体检 / 离职证明）

## 快速补数据路径（〔待核〕→ 可用，48 小时内）

对方已报价、探底分支失效、手上只有〔待核〕时，按可靠度从高到低补：

1. **在职朋友实数**（目标公司或同梯队同岗）——最硬；进 Brief 校准，卡面匿名泛化（见 brief-guide 可引用性分层）
2. **猎头报价交叉**（问 2 家以上，猎头有夸大动机，取交集不取上限）
3. **公开招聘 JD 报价区间**（同城同级岗位，注意 JD 区间上限常为职级带宽顶不是实发）
4. **社区曝光帖**（匿名论坛/职场社区）——可靠度最低，只作方向参考，**不升级为可引用来源**，仍标〔待核〕

补不到 → 维持〔待核〕纪律，锚定走「后报探底」或「争取答复时间窗」，不硬造数字。

## 语域注记

- 谈薪对话全程用「商量 / 对齐 / 了解」类动词框架，不用「要求 / 必须 / 谈判」自指（「我们谈判一下」在中文语境里自带对抗预设）。
- 对方给了让步，接住时确认价值（「这个 review 机制对我很重要，谢谢你去争取」）——让对方的让步在他的叙事里也是胜利，他才让得下去。
- **体制内 / 国企语境**（Brief 标注刚性带宽时全程生效）：编制内 base 与职级序列基本不可动（带宽制度刚性远高于市场化公司），**可谈的**是定级认定（解锁下一档带宽的杠杆）、津贴与补贴口径、培训 / 借调 / 外派资源、核心项目署名与主导——期望管理先行，把谈判重心从「数字」转到「组织资产」；rubric fatal #2 对此场景有豁免分支（见 negotiation-rubric）。
