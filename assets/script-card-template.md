# Script Cards（模板）

> 措辞纪律与各卡型要点见 `references/script-card-patterns.md`。每张卡 ≤ 半屏、可扫读、只引用 Brief 事实。

```markdown
## 谈判话术卡 · {场景} · {日期}

> 筹码陈述（随身提醒）：{Brief 的 BATNA 一句话}
> 底线：{数字/条件} → 触线动作：{转议题 / 体面收场 / 走}

### 🟢 开场卡
{感谢/关系句} → {目的直陈} → {框架预告}

### 🎯 锚定卡（分支：先报精确锚 / 后报探底）
- 台词：
- 依据陈述（一句）：
- 报完之后：闭嘴等回应，不自行找补

### 🛡 异议应对卡
#### 卡 1 · {招数名}
【对方说】
【你答】
【逻辑】

#### 卡 2 · {招数名}
【对方说】
【你答】
【逻辑】

（按 Brief 对方视角表预判的招数逐张建，场景 top 压力招必须覆盖）

### 🤝 收尾卡
- 复述确认：
- 落字清单（谈薪场景参照 cn-workplace-notes.md offer 细节清单；拒绝场景=关系维护句；坏消息场景=决策请求明确化）：
- 下一步与时间点：

### ⚠️ 场外提醒
- 不想答的问题 → 转向句（不撒谎，会转向）：
- 情绪上头信号 → 暂停句：「这点我记下来，我想想再回你」
- 〔待核〕数据清单（卡面禁用，谈前能补则补）：
```
