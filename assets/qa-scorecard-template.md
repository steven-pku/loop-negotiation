# QA Scorecard（模板）

> ⚠️ **分数是方向性诊断，不是校准门槛**：合计 /100 只看方向（Pass / Borderline / Revise）与有无 fatal，同稿跨模型可差数十分，勿跨稿比点数、勿为追分优化。
> 评分锚点与 fatal 判定细则见 `references/negotiation-rubric.md`（非谈薪场景先看「场景适配注记」）。先审计后打分；每处扣分引用卡面原句（QA Only = 用户原文原句）。

```markdown
## QA Scorecard · QA loop: N/2

### 真实性与筹码审计（不过 = fatal，不进入打分）
- 卡面主张全部可回溯 Brief：✅ / ❌（列出卡外主张）
- 市场数字三选一标注齐全、〔待核〕未变实数：✅ / ❌
- 无虚构筹码（假 offer / 编造 deadline / 无支撑威胁）：✅ / ❌
- 卡面与 BATNA 陈述、底线、阶梯一致：✅ / ❌

### 六维评分
| 维度 | 得分 | 满分 | 扣分点（引原句） |
|---|---:|---:|---|
| 目标三层与底线 | | 20 | |
| 对方视角完整度 | | 20 | |
| 让步阶梯与交换 | | 20 | |
| 开场与锚定 | | 15 | |
| 异议应对覆盖度 | | 15 | |
| 语气与关系 | | 10 | |
| **合计** | | 100 | |

### Fatal issues
- 命中：无 / 【#N】＋卡面原句

### 方向判定
- Pass / Borderline（最弱维：___，定向修一轮）/ Revise
- 修订规则（好例格式见 rubric 末节，坏例「加强 XX」禁用）：
  1. …

### 下一步
- 进 mock（Pass 后必跑）/ 定向修订 / Graceful Halt（2/2 已到：最佳版本 + 未解缺陷 + 缺口清单）
```
